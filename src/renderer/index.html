          Sessions started outside Frugal Deck
          
    Claude Code CLI and Claude Desktop sessions in your accounts folders. Chats you open here are added on their own.
    
          
    
            
            
          
    
          
    
        
    
        
    
          
          
    Plays the notification sound when you let go.
    
        
    
      
    
      
    
        
    Appearance

    Where help like this appears.

    Chats
    
        
    
          
          
    Needs the Frugal plugin in the account. Applies to chats started after the change.
    
        
    
        
    
          
          
    Uses Claude Code's fullscreen renderer. Applies to chats started after the change.
    
          
    May not work as expected. It overrides Claude Code's fallback to the classic renderer after failed starts. Turn it off if chats fail to start, flicker or draw wrong.
    
        
    
      
    
      
    
        
    Handoff
    
        
    
          
          
    From 150K tokens of context, a handoff opens a new chat after the delay. Off, it waits for Continue in new chat.
    
        
    
        
    
          
          
    0 starts the new chat as soon as the handoff is ready, with no countdown.
    
        
    
        
    
          
          
    A box under the handoff for more context. Typing in it pauses the countdown.
    
        
    
      
    
      
    
        
    Permissions
    
        
    
          
          
    Accepts Claude Code's trust check in every folder you open here.
    
          
    A folder's own settings and hooks can run commands as soon as the chat starts. Only for folders you know.
    
        
    
        
    
          
          
    Claude runs commands and edits files without asking. Applies to chats started after the change.
    
          
    An error or a malicious instruction in a file or page can cause damage before you can stop it. Anthropic recommends it only in isolated containers or virtual machines.
    
        
    
        
    
          
          
    Windows asks for permission the first time. Applies to chats started after the change.
    
          
    Claude can change system configuration, services, programs and any user's files. Those changes can leave Windows unstable or insecure.
    
        
    
      
    
      
    
        
    Accounts
    
        
    
          
          
    Applies to chats started after the change.
    
        
    
        
    
          
          
    Sets cleanupPeriodDays to 3650 in every Claude account, so Claude Code stops deleting transcripts idle for 30 days. Off removes only that value.
    
          
    
        
    
      
    
      
    
        
    Voice
    
        
    
          
          
    Win+H starts Windows dictation in any app, with no download.
    
        
    
        
    
          
          
    Downloads on first use, after showing its size.
    
        
    
        
    
          
          
    The language you speak in.
    
        
    
      
    
      
    
        
    Privacy
    
        
    
          
          
    Ask AI (Ctrl+Shift+K) also sends Anthropic up to 200 characters of a matching message from each of up to 40 chats.
    
          
    Parts of your conversations leave this computer.
    
        
    
        
    
          
          
    Local dictation records with it. Off, it stays blocked.
    
        
    
        
    
          
          
    Ctrl+V in a chat reads it. Off, Ctrl+V pastes only images.
    
        
    
      
    
      
    
        
    Activity
    
        
    Account sign-ins and sign-outs, MCP servers that ask to sign in, plugins added or updated in the Deck's store, Import and clean results, and chats left on their old settings. Saved to ~/.frugal-deck/activity.jsonl.
    
        
    
          
    
            
    Loading activity
    
            
          
    
          
    
        
    
      
    
      
    
        
    Debug
    
        
    
          
          
    Records chat starts and exits, handoffs, calls between the window and the Deck, events, clicks and errors. Also saved to ~/.frugal-deck/debug.log, so it survives a restart. Times are UTC.
    
          
    Uses some extra CPU and disk while on. The log holds folder paths and the start of prompts; it stays on this computer.

    Frugal Deck will accept Claude Code's trust check for you in every folder you open here. Claude Code will be able to read, edit, and execute files there, and a folder's own settings and hooks can run commands as soon as the chat starts.
