    Claude runs commands and edits files without asking. Applies to chats started after the change.
    
          
    An error or a malicious instruction in a file or page can cause damage before you can stop it. Anthropic recommends it only in isolated containers or virtual machines.

      Frugal Deck will accept Claude Code's trust check for you in every folder you open here. Claude Code will be able to read, edit, and execute files there, and a folder's own settings and hooks can run commands as soon as the chat starts. A folder you downloaded or did not write could harm your computer or expose your files and credentials.
