Frugal Deck is a desktop client for Claude Code, built around the Frugal skill. It runs Claude Code's own terminal with tabs, groups and search, delegates work to your other accounts so your limits last longer, and leaves out the noise of Claude Desktop.

Everything stays on this computerFrugal Deck has no servers and collects nothing. Your sessions, groups and settings live in your user folder. Claude Code talks to Anthropic as it always does.

They stay where they are; Frugal Deck only lists them. You can change this later in Settings.

Install in

Administrator chats are safest in a folder only administrators can change, like Program Files.

Frugal Deck keeps one copy of each plugin and MCP server and shares it with every Claude account. Pick what to import, keep or remove.

Everything changed is backed up first; uninstalling can restore it. Old plugin copies are not backed up: Claude Code downloads them again if needed.
